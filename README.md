# NEET Study Platform

Fresh React + TypeScript NEET UG application.

The previous App(7).tsx was used only as an architectural reference for useful ideas such as authentication, bookmarks, notes, mistakes, daily progress, practice flow and mock-test flow. This is a new product, not a restyled MBBS app.

## Included
- NEET branding
- Physics, Chemistry, Biology
- Botany / Zoology positioning
- Home dashboard
- Practice/search
- Saved Questions
- Mistake Bank
- Mock Tests
- Normal Practice / CBT / PDF mode selector
- Progress and Daily Target
- Mobile/tablet/desktop responsive layout
- No fabricated question bank

## Questions
Add real questions in `src/data/questions.ts` using the documented schema.

## Supabase
Copy `.env.example` to `.env` and add your Supabase URL and anon key.
